# Precios

Lista de precios de supermercados, con filtros por lugar, categoria y fecha.

Dos fuentes, siempre separadas:

- **Precios Claros (SEPA)**: precios de gondola oficiales de cadenas (Vea, La Anonima, HiperChangomas), generados desde la API de Precios Claros.
- **Relevado a mano**: precios de fiambrerias y comercios de barrio, cargados por la familia.

Generado automaticamente desde /opt/data/precios (Hermes Agent). No editar a mano.
